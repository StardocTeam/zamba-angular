Standalone test page for zamba-tinymce-editor

This page loads the custom element bundle from dist/elements, creates a zamba-tinymce-editor instance, and lets you test both local DOCX flows and the Zamba-backed load/save flow with explicit properties.

Expected preparation: run npm run build:elements before opening this file. The page now loads the elements bundle automatically.

Suggested test flow

  • Run npm run build:elements and then open this page from the repository root.
  • Use Prepare local-only mode when you only want to test opening and exporting DOCX from the PC.
  • Use Fill sample IDs as a quick scaffold, then replace them with real values and optionally a token to exercise the Zamba integration.
  • If you change inputs after the editor exists, click Apply properties; if you want a completely fresh instance, click Create editor.
