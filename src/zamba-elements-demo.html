Note: this demo expects the element bundle files to be served from ./dist/checklist-element/ alongside this page (runtime.js, polyfills.js, main.js).

If you built with `--output-hashing=none`, the filenames will be stable. Adjust the script src paths below to match your build output.

Example usage

Notes & tips

  • Setting numeric inputs through attributes converts them to strings; prefer setting properties from JS (el.reportId = 123).
  • To support an external refresh API without recreating the element I can add a small CustomEvent listener in the component (e.g., listen for refresh events).
  • If the bundle is large, consider serving common libs separately or using module federation / ESM build optimizations.
